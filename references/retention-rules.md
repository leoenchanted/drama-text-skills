# Retention Rules for Short Drama Scripts

## 目标

短剧爆款文案的优先级不是文学性，而是留存。写作时把剧情当素材，把观众的情绪奖励当主线。

核心指标：

- 节奏密度：不能停。
- 冲突频率：必须持续。
- 爽点间隔：约 10-20 秒一次，落到 800-1000 字中文稿中约为每 60-100 字一次。
- 升级感：后面的冲突必须比前面更大。

## 必须限制 AI 的四件事

1. 不准慢铺垫。
2. 不准长解释。
3. 不准连续温吞情绪戏。
4. 不准只讲剧情、不制造奖励。

## 高频爽点元素

每个节奏点至少包含一种：

- 冲突：被羞辱、被威胁、被误会、被围攻。
- 打脸：反派刚放狠话，马上被事实反杀。
- 反转：观众以为 A，下一秒变成 B。
- 震惊：全场沉默、所有人傻眼、反派慌了。
- 技能展示：主角露出超规格能力。
- 身份反差：普通身份背后是大佬、豪门、救命恩人、掌权者。
- 危险倒计时：灾难、 deadline、秘密即将暴露。

## 标准爽点循环

优先使用：

压制 → 质疑 → 主角出手 → 全场震惊 → 反派升级 → 再次打脸

变体：

- 重生复仇：前世受害 → 这一世预判 → 反派自信 → 主角设局 → 反派入套 → 命运改写。
- 隐藏大佬：被看不起 → 主角淡定 → 小露一手 → 众人不信 → 更高身份出现 → 当场封口。
- 闪婚霸总：孤立无援 → 渣男羞辱 → 权势人物出现 → 关系揭露 → 全场变脸。
- 灾难逃生：没人相信 → 第一个证据出现 → 倒计时逼近 → 自私者作死 → 主角提前布局。

## 文案节奏换算

如果用户没有给精确时长，按 800-1000 字短视频解说估算：

- 前 60-80 字：必须强钩子。
- 每 60-100 字：一次刺激点。
- 每 150-250 字：一次冲突升级。
- 每 200-300 字：一次视觉高潮。
- 最后 80-120 字：身份反转、危机逼近或下一集悬念。

## 开头钩子公式

优先使用结果前置：

- 她刚准备领证，就撞见未婚夫和闺蜜背叛她。
- 所有人都以为这个男人只是穷小子，可下一秒，整个集团都为他让路。
- 女人刚重生，就知道三小时后巨大的灾难会吞掉整个村子。
- 他逃婚只是想摆脱家族安排，没想到误闯进一个单亲妈妈的家。

避免：

- 某某是一个普通女孩。
- 故事发生在一个普通的早晨。
- 今天要讲的是一段复杂的感情故事。

## 主角稳定感

高爽感主角要像“已经知道答案的人”：

- 少崩溃，多冷静。
- 少解释，多行动。
- 被羞辱时不急着辩解，等证据或底牌出手。
- 可以受伤，但不能长期被动。
- 可以隐忍，但隐忍必须服务后续打脸。

## 禁止内容

- 大段人物背景。
- 复杂对话复述。
- 过多心理活动。
- 只讲因果不制造情绪波动。
- 反派只骂不升级。
- 主角一直解释却没有行动。
- 结尾平铺直叙。

## 自检问题

生成前问自己：

- 前 3 秒有没有让人停下来的信息？
- 最近 100 字有没有刺激点？
- 反派是否越来越过分？
- 主角是否越来越显得有底牌？
- 有没有一个让观众想继续看的未解问题？
